
# SISTEMA DE GESTIÓN DE TIENDA

## Objetivo

Desarrollar una aplicación web profesional para
administrar una tienda física.

## Tecnologías

Frontend:

- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React
- Recharts

Backend:

- Node.js
- TypeScript

Base de datos:

- PostgreSQL

Pruebas:

- Playwright

## Módulos principales

1. Dashboard
2. Inventario
3. Punto de venta (POS)
4. Estadísticas
5. Contabilidad
6. Clientes
7. Proveedores
8. Usuarios y permisos
9. Configuración

## Reglas de desarrollo

1. Utilizar componentes reutilizables.
2. Mantener una arquitectura modular.
3. Implementar diseño responsive.
4. Utilizar TypeScript.
5. Evitar código duplicado.
6. No instalar dependencias innecesarias.
7. Validar formularios.
8. No almacenar contraseñas en texto plano.
9. Implementar control de acceso por roles.
10. Crear pruebas para operaciones críticas.
11. No modificar módulos sin analizar dependencias.
12. No implementar funcionalidades no solicitadas.

## Diseño

La aplicación debe tener una interfaz moderna,
minimalista y profesional.

Características:

- Sidebar lateral.
- Dashboard con indicadores.
- Tablas interactivas.
- Formularios intuitivos.
- Navegación sencilla.
- Modo claro y oscuro.
- Diseño adaptable a tabletas.

## Metodología

Antes de desarrollar una funcionalidad:

1. Analizar los requisitos.
2. Proponer la solución.
3. Implementar.
4. Ejecutar pruebas.
5. Corregir errores.
6. Documentar los cambios.
